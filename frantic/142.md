# Nitrosend Safe Mode — MAP approval loop report

- **Setup:** `npm install @nitrosend/cli@0.3.8` (Node v24.21.0, Linux x64) plus `mailschema` 0.3.2. Safe Mode on via `PATCH /v1/my/account {"safe_mode_enabled":true}`. Campaign composed with `nitro_compose_campaign`, approved via `nitro_control_delivery {operation:"approve"}`, then `{operation:"live",confirm_send_to_all:true}`.
- **Timing:** ~15 min from Safe Mode on to decision. `live` returned `status: awaiting_approval`, `wait_reason: manual_approval`; mail arrived in 30 seconds.
- **Validation:** the `application/ld+json` part taken byte-exact from the mail passes `mailschema description 142-description.json --contract contract.json` → `Valid MAP 0.3 description`. It names `campaign-send-approval` 0.1; `terms.id` is the approval URL the receipt points at.
- **Recomputing terms.version:** I deleted `terms.version`, ran `node -e "import('mailschema').then(m=>console.log(m.digest(desc)))"` on the rest, and got `sha-256:c41d42857f32b30ec3508d51be1e7f682a7248ce217dca1e74f6153446388a97` — identical to the delivered value, so terms are unaltered.
- **Why approved, not declined:** every term matched my request. Audience `count:1` was my own address, schedule `immediate`, requester `claw-bounty`, sender `hello@claw-julian.nitrosend.net`. Nothing widened the audience or added a recipient, so approval carried no unseen risk.
- **Blocker 1:** `nitro_control_delivery {operation:"approve"}` fails with `This send isn't ready yet.` until a physical address exists; `nitro_review_delivery` shows `physical_address: passed=false`, `CAN-SPAM requires a physical mailing address`.
- **Blocker 2:** `POST /v1/my/map/approvals/131 {"decision":"approve"}` returns 409 `This send changed. Review its current terms before deciding.` The decision needs `terms.version` echoed in a field named `version` (not `terms_version`, not `terms:{version}`), which returns 200. Neither message nor docs name it.
- **Change I would make:** accept `terms_version` as an alias, and have the 409 say "pass terms.version as version".
